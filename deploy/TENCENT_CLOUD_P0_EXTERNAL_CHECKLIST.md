# 腾讯云 P0 历史外部操作清单

以下项目必须由具备腾讯云、域名和火山引擎权限的操作者在真实生产账号完成。仓库代码无法替代这些账号级操作。不要在本文件记录任何密码、API Key 或 Token。

## 网络与主机

- [ ] CVM 使用受支持的 x86_64 Linux，系统补丁已更新。
- [ ] 独立 CBS 挂载到 `/srv/golden-mic-data`，不是根盘目录或临时盘。
- [ ] CBS 快照、70%/85% 容量和 inode 告警已启用。
- [ ] 安全组未开放 TCP 8000。
- [ ] SSH 22 仅允许固定运维 IP；应用用户只经 80/443 访问。
- [ ] 固定 EIP/NAT 出口已记录，用于 Provider 来源限制。
- [ ] NTP、DNS、HTTPS 和 WSS 到目标火山引擎地域实测通过。

## 域名、TLS 与访问控制

- [ ] 域名解析指向受保护入口；中国大陆公网场景已完成 ICP/合规确认。
- [ ] TLS 证书有效，自动续期和续期失败告警已验证。
- [ ] 已明确选择 `PUBLIC_ACCESS_MODE=anonymous` 或 `authenticated`，且 Nginx 安装参数与环境配置一致。
- [ ] 匿名模式：签名密钥在服务器本机随机生成，界面无登录可访问，缺会话/CSRF 的上传在传输大请求体前被拒绝。
- [ ] 匿名模式：腾讯云 WAF、会话/IP/全站额度、Provider 日预算和异常费用告警均已实测。
- [ ] 若使用 CLB/CDN，仅信任腾讯云官方代理网段重写真实客户端地址，并已确认不同公网客户端不会共享同一个后端 IP 额度。
- [ ] 认证模式：Basic Auth 文件由操作者在服务器终端交互创建，权限为 `root:www-data 0640`；正式多用户场景已评估 OIDC/Zero Trust。
- [ ] Nginx、CLB、WAF 和 CLS 均确认不记录 query string 中的任务 token。

## 发布供应链

- [ ] 项目已纳入私有 Git 仓库；发布提交、审计记录、CI 结果和 release-id 可追溯到不可变 commit/tag。
- [ ] main 分支启用评审、CI 必须通过和禁止强推；生产发布有变更单与双人复核。
- [ ] Minisign 生产私钥在隔离签名机交互生成并加密保存，不进入服务器、仓库或 CI。
- [ ] 对应公钥以 `root:root 0644` 安装到 `/etc/golden-mic/release.pub`。
- [ ] 每次发布同时提供归档、SHA-256 和 `.minisig`，篡改归档/签名的拒绝测试已通过。
- [ ] 发布与回滚中断演练确认旧服务不会永久停留在 drain 状态。
