## 改动范围

目标是让非剪辑专业用户更容易完成现有流程，不新增或删减制作能力。

- 写稿、传素材、选效果保持三步流程。配音与字幕直接显示；语速、音乐、画面效果等收进“更多设置”，控件保持挂载，收起不重置值。
- 五要素自查、拍摄清单、逐句画面自查与估算公式改为按需展开。上传错误、原话门槛、隐私与费用提醒保持可见。
- 制作页先显示当前进度，“查看制作步骤”保留全部十个阶段，失败时展开。
- 结果页突出预览、逐句修改、发布检查和导出。版本记录、重命名、复制、删除及 MP4 参数按需展开；五种导出格式保留。
- 减少粗边框、重阴影与装饰；手机句子列表自动换行。修复结果页播放快捷键拦截原生展开按钮空格键的问题。
- 后端、接口、默认偏好、来源验证、收费授权与发布门禁未改动。参见更新后的[使用指南](USER_GUIDE.md)。
