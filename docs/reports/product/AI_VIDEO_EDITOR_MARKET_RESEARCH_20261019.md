## 1. 范围与证据口径

- **限定**：受套餐、地区、平台、语言、硬件、上游模型或额度影响。

## 2. 按生产环节划分功能

| 环节 | 应当分别比较的功能 |
|---|---|
| 选题与文稿 | 从要点写稿、润色、摘要、文章/PDF/PPT 转视频、分镜规划、事实审校 |
| 素材整理 | 上传/本地导入、转写、说话人分离、场景检测、OCR、标签、语义搜索、版权素材库 |
| 初剪 | 文本删剪、剧本匹配 takes、采访摘要、自动 B-roll、长转短、自动多机位、音乐卡点 |
| 人工精剪 | 时间线、片段排序、分割、波纹/滚动/slip/slide、关键帧、嵌套序列、代理 |
| 声音 | TTS、本人录音、声克隆、降噪、人声分离、去静音/口头词、响度、混音、ducking |
| 字幕 | ASR 字幕、逐词时间、校正、样式、翻译、SRT/VTT/ASS、字幕与声音分别修改 |
| 画面 | 自动构图、跟踪、蒙版、抠像、防抖、调色、HDR、降噪、超分、插帧 |
| 包装 | 标题、人名条、模板、贴纸、品牌套件、图表、MG 动画、片头片尾 |
| 生成式补充 | 文生/图生视频、镜头延长、对象修改、生成音乐、数字人、译配对口型 |
| 审阅与资产治理 | 版本、评论、审批、协作、来源记录、授权、AI 标识、保留期、访问控制 |
| 交付 | 分辨率/帧率/画幅、编码格式、工程互通、批量输出、平台发布、排期 |
| 经营与运维 | 软件许可、席位、素材授权、积分、输入分钟、存储、部署、隐私和支持 |

## M01 剪映：中国版专业剪辑与短视频生态

**定位**：桌面专业版与移动端并存，兼有通用剪辑、短视频包装和 AI 创作。不是仅有“一键成片”的网页工具。

- **常规编辑**：官网明示蒙版、关键帧、调色、多机位、多时间线、音频剪辑。移动端说明包含分割、变速、倒放、多比例画布、转场、贴纸、字体和滤镜。
- **AI**：智能剪口播、镜头分割、语音字幕、文本朗读、智能抠像、超清画质、智能调色、补帧、美颜、人声处理；还列音色克隆、数字人、AI 音乐、营销成片和智能文案。
- **生态**：模板、音乐、贴纸、学习中心和创作者内容是产品的一部分；学习中心明确提醒音乐侵权问题。
- **限定**：桌面、多机位等能力不能直接算到每个手机版本；即梦是相关独立入口，不能把即梦全部模型功能等同剪映内置。内购、会员、云空间和 AI 权益需要按客户端核对，没有可靠统一“永久免费全部功能”结论。
- **与金话筒相关**：最重要的广度参照，尤其是精剪、字幕、包装、素材生态和移动端；官网没有给出与金话筒 C 模式完全同构的“原话连续性准入”证据，不能因此断言其没有其他安全机制。

来源：[剪映专业版官网](https://www.capcut.cn/)、[剪映创作课堂](https://www.capcut.cn/learning)、[中国 App Store 开发者功能说明](https://apps.apple.com/cn/app/id1458072671)。

## M03 Adobe Premiere：专业 NLE 加 AI 辅助

- **编辑**：三点剪辑、文本式剪辑、复杂时间线、标题/效果、音频混音和调色；多机位帮助明确按音频、时间码、标记或入出点同步。
- **AI**：Media Intelligence 按物体、地点、构图等查素材；转写后按文本整理/重排/裁剪；对白增强；音乐自适应时长；字幕翻译；Auto Reframe 根据动作生成重构图结果，仍可能需人工调关键帧。
- **生成扩展**：Generative Extend 帮助页列联网生成，视频最多延长 2 秒、音频最多延长 10 秒；生成区域带标记。不能将音频延长解释为任意克隆人物新对白。
- **协作**：套餐包含 Frame.io 审阅/批准。审片评论不等于无限制多人同时编辑一条时间线。
- **限定**：订阅与生成积分分别预算。当前产品页把 **Color Mode 与重新设计的形状蒙版标为 Beta**；不应将其当成所有正式版本默认能力。桌面与新移动产品也要分开。
- **参考价值**：适合作为金话筒初稿的下游精修目标，以及语义搜索、文本剪辑、专业工程交接的对标。

来源：[产品](https://www.adobe.com/products/premiere.html)、[转写/文本剪辑帮助](https://helpx.adobe.com/premiere-pro/using/text-based-editing.html)、[Generative Extend](https://helpx.adobe.com/premiere-pro/using/generative-extend.html)、[多机位](https://helpx.adobe.com/premiere-pro/using/create-multi-camera-source-sequence.html)、[Auto Reframe](https://helpx.adobe.com/premiere-pro/using/auto-reframe.html)、[套餐](https://www.adobe.com/products/premiere/plans.html)。

## M04 DaVinci Resolve / Studio：剪辑、调色、音频与合成一体

- **常规专业能力**：Cut/Edit、精确修剪、多机位同步、关键帧、节点调色、Fusion 合成、Fairlight 音频、字幕和多种专业交付。
- **AI**：官网当前展示 Resolve 21。IntelliSearch 查找物体、对白和人物；IntelliScript 将稿本与已转写录音匹配成初剪；Magic Mask、Smart Reframe、Voice Isolation、降噪和智能图像处理。
- **新语音功能**：当前新功能页明确列 AI Speech Generator，可用内置声线或样本生成声音；不能再简单写成“Resolve 只有降噪，没有 TTS”。中文和每项授权范围仍须核对。
- **协作/交付**：多人项目协作与 Blackmagic Cloud；可直接输出至部分视频平台。Cut 页还有长镜头和跳切提示，说明“质量辅助”并非金话筒独有概念。
- **限定**：免费版与付费 Studio、云存储和硬件各自计费；新功能页不代表所有 Neural Engine 工具免费。没有充分证据时不把多机位同步推断为当前自动按说话人切镜，也不把光流慢动作算生成式续拍。
- **参考价值**：专业后期和工程互通的重要目标；也是素材语义搜索与稿本初剪的直接参照。

来源：[新功能](https://www.blackmagicdesign.com/products/davinciresolve/whatsnew)、[Edit](https://www.blackmagicdesign.com/products/davinciresolve/edit)、[Cut](https://www.blackmagicdesign.com/products/davinciresolve/cut)、[Studio](https://www.blackmagicdesign.com/products/davinciresolve/studio)。

## M05 Final Cut Pro：Apple 生态专业剪辑

- **编辑/包装**：磁性时间线、修剪、标题、转场、效果、插件、调色轮/曲线/LUT；专业音频效果和批量导出，Compressor 提供更多交付控制。
- **AI**：Magnetic Mask、对象跟踪、光色增强、慢动作、自动重构图、音乐节拍检测、自动字幕、Visual Search 与 Transcript Search。
- **平台边界**：Mac 与 iPad 不同；官网明确的四设备 Live Multicam 是 iPad 工作流。不能将 iPad 能力和桌面能力混成一份无条件清单。
- **语言边界**：当前官网脚注将 Visual Search、Transcript Search 限定为**美式英语**，并列 Apple silicon/系统要求。不能以英文搜索演示证明中文新闻素材检索已支持。
- **费用**：Mac 一次性购买与 Apple Creator Studio 订阅并存；不能把其他创意应用或插件都算作单独 FCP 许可权益。
- **参考价值**：高效手工精剪、自动构图和包装；不宜把转写搜索当成已证明的“删字即剪视频”全部流程。

来源：[产品及脚注](https://www.apple.com/final-cut-pro/)、[Mac 用户指南](https://support.apple.com/guide/final-cut-pro/welcome/mac)。

## M10 花生 AI：与稿件驱动成片最贴近的国内参照之一

- **输入/成片**：文稿拆分镜、自动找/剪素材、配音、字幕；支持自己的素材并逐分镜替换，也支持口播音频成片。
- **编辑**：自然语言对话修改素材、声音、字幕、动画；MG 图形动画；自己的音色克隆；横/竖屏。
- **细颗粒度修订**：官方教程明确提供“只改字幕不改配音”；它比笼统的“文字转视频”更值得比较，因为真实用户需要低成本纠错。
- **页面边界**：文稿展示 200–10000 字、口播音频最长一小时、会员列1080p/无水印和花生米额度。它们是本次页面声明，不是实际处理速度/中文质量验收。

- **参考价值**：金话筒应优先比较它的分镜、改稿联动、素材替换、模板/MG，而不是只比较剪映功能总数。

## 3. 费用和“成熟”的横向结论

| 类型 | 主要成本 | 容易误判的地方 |
|---|---|---|
| 专业桌面 NLE | 订阅/买断、插件、硬件、素材、部分云 AI | 买断不代表无限 AI；硬件加速不是所有电脑同速 |
| 移动短视频 | 会员、内购、素材、云空间、AI | 免费安装≠全部字幕/素材/生成免费；音乐库≠任意商业新闻授权 |
| 文本/在线编辑 | 席位、输入媒体小时、存储、AI credits | 上传分钟、生成分钟、输出分钟不同；团队评论≠所有人都能实时共编 |
| 生成式/数字人 | 模型、像素/时长、credits、头像/语音、企业许可 | 重生成多次才满意会增加成本；“生成10秒”≠“可用成片10秒” |
| 自建金话筒 | 自有机器/存储/运维、ASR/TTS/视觉/向量/LLM/生成 API、人工审校 | 没有 SaaS 席位费≠零成本；开始前的预转写和写稿助手也可能收费 |

推荐采购比较口径为“**一条验收通过视频的总成本**”：包含素材整理、模型失败重试、人工纠错、审稿、存储及导出，而不是只比较官网最低月费。没有一致样本和真实账单，本报告不提供哪家便宜多少、快多少、准确多少的伪量化排名。
