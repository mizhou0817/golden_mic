## 3. 文稿与新闻结构

### P01 稿件输入与结构化（V2）

- 第一行标题1–40字，末尾不加规定的句末标点；正文非空，标题不作为旁白。
- A/B整份稿件至少20字；总上限8000字，3000字为提示精简的软限。句子最多200个；单句编辑上限2000字。
- 支持识别旁白/同期及姓名身份前缀，客户端确认的句子必须与完整稿件内容绑定。
- 五要素自查、长句提示、拍摄清单和复制清单帮助准备素材；它们不是外部事实检索。
- 没有 Word/PDF/PPT/新闻网页的完整导入成片入口，没有多人富文本协作。

依据：[服务端稿件和身份校验](../../../backend/drafts.py#L830-L974)、[共用规则](../../../backend/mode_rules.json#L1-L35)、[向导写稿/自查](../../../frontend/src/components/CreateWizard.tsx#L1230-L1302)。

### P02 AI 写作助手（V2＋云服务条件）

- 从事实要点写稿，短/中/长目标约150/300/500字；润色、精简、口播化、庄重化或自定义要求。
- 返回稿件先预览，用户采用才覆盖；支持取消、重试、放弃、撤销采用；C模式不开放AI写稿。
- 要点最长2000字、助手输入/输出稿件最长3000字、修改要求最长300字；这是助手限制，**不是一般稿件8000字上限**。
- 独立调用已配置LLM；当前有限并发和每客户端/全站调用频率限制，且可能在创建任务前收费。
- 数字变动会给出警告，但没有自动核实姓名、事件、日期、因果或外部资料。

**静态核查发现的保护边界**：`QUOTE_LINE` 只识别行首 `同期：` / `同期:`。它没有覆盖向导示例的“同期 王红（身份）：……”这种前缀，因此不能称为“所有同期格式逐字受保护”。这里只确认正则和校验路径，不声称做过真实模型错误复现。

依据：[助手实现与校验](../../../backend/script_assist.py#L15-L115)、[实际API与限额](../../../backend/main.py#L704-L760)、[助手UI](../../../frontend/src/components/ScriptAssistant.tsx#L9-L106)。

### P03 AI 自动选效果（V2，允许规则回退）

- 根据稿件选择语气、速度、音乐、推近、淡入淡出、新闻图文、颜色、字幕等白名单选项，支持撤销。
- 模型未配置、繁忙、失败或45秒超时等情况下使用本地关键词规则；返回值区分 `source="ai"` / `"rules"`。
- 不改变用户配音意图、不覆盖自定义剪辑要求、不自动开启收费生成补画面。
- **不等于自动完成整条视频**：它只是设置偏好。当前界面仍统一显示“AI 已选好”，没有按 `source` 明示规则回退，这是透明度边界。

依据：[规则与模型选择](../../../backend/effects_suggest.py#L1-L125)、[API回退](../../../backend/main.py#L763-L790)、[前端解析](../../../frontend/src/lib/effectsSuggest.ts#L1-L34)、[UI应用与提示](../../../frontend/src/components/CreateWizard.tsx#L390-L407)、[效果区](../../../frontend/src/components/CreateWizard.tsx#L1368-L1441)。

## 4. 素材输入、管理与预处理

### P04 视频、照片和源裁剪（V2）

| 项目 | 当前源码上限/语义 |
|---|---|
| 视频容器 | MP4、MOV、AVI、MKV；最终仍需真实解码/探测通过 |
| 图片 | JPG/JPEG、PNG、GIF；GIF按首帧作为照片，不保留动画 |
| 每作品 | 最多20文件、总计5 GiB；一般单文件500 MiB |
| 图片独立限制 | 50 MiB、2000万像素；还受几何等检查，不等于能用500 MiB图片 |
| 源时长 | 单个最长1800秒、总计3600秒，按原始时长计，不因裁剪豁免 |
| 源几何 | 默认最大7680×4320、120fps；不是8K/HDR成片承诺 |
| 单素材备注 | 最多20字；参与素材理解/检索上下文 |
| 创建阶段裁剪 | 起止整秒，或完整源EOF；不是任意帧级剪辑台 |
| 上传块 | 8 MiB，带文件身份/摘要/长度和任务绑定 |
| 同owner暂存配额 | 最多100文件、20 GiB；跨草稿计算 |

所有值还受服务器更严格配置制约。本次未读取实时 limits。

依据：[媒体选择与裁剪](../../../frontend/src/lib/mediaInput.ts#L1-L119)、[上传硬上限](../../../backend/uploads.py#L70-L128)、[配置默认](../../../backend/config.py#L90-L149)。

### P05 上传恢复与预转写（V2＋ASR条件）

- 任务级草稿先取得回执，再添加文件/分块；传输完成、probe通过、转写完成是不同状态。
- 浏览器不支持的媒体可在限定条件下走服务端元数据探测；必须拿到真实时长/尺寸才继续收费处理。
- 每块检查长度/文件摘要；完成时复核拼装内容，重复或中断通过已收分块对账而非盲目重传全部。
- 页面提供重新读状态、续传、重试失败素材、移除素材和5秒内撤销移除；没有原始 `File` 的未完成上传仍需要重新选择。
- 预转写采用云ASR，语音存在检测、词/段时间、说话人和波形供后续原话匹配；缓存/已有回执可复用，GET本身不应重新转写。
- 上传和预转写发生在显式start之前；本地开始次数额度不是这些费用的总金额上限。

**当前近期变化**：慢连接收块已移到全站草稿锁外；块超时为120秒固定余量加“字节数/8000字节每秒”。8 MiB约1168.6秒，并非旧的固定120秒。这里只确认机制，未做慢网吞吐压测。

依据：[上传页面](../../../frontend/src/components/CreateWizard.tsx#L1302-L1367)、[实际分块与探测路由](../../../backend/drafts.py#L778-L833)、[ASR发送前预算检查](../../../backend/drafts.py#L410-L440)、[超时计算](../../../backend/uploads.py#L102-L113)。

### P06 素材充足度与回退（V2）

- 创建页按普通视频每12秒估计一个镜头，图片/已知语音素材按一个计；不是实际切镜，也不是匹配通过保证。
- 匹配优先不同镜头；**当前 `_shot_reuse_accepted()` 默认允许复用，只有内部明确 `accepted=False` 才坚持严格不重复**。
- 同一真实素材可以分窗口、串多个窗口，必要时回到开头循环；渲染前还按实际配音时长补足覆盖。
- 这些窗口有不同逻辑ID；因此“逻辑ID唯一”不能代表物理内容未重复。也不能把该链条表述为语义丰富的多镜头规划。
- 完全没有可用画面、源不可解码、证据错误或最终覆盖仍不足时仍可能失败；“素材不够也一定做完”不是源码能保证的通用结果。

依据：[估算](../../../frontend/src/lib/mediaInput.ts#L124-L150)、[默认复用策略](../../../backend/mode_pipeline.py#L758-L779)、[窗口分配/循环](../../../backend/mode_pipeline.py#L785-L928)、[正式流程调用](../../../backend/mode_pipeline.py#L1925-L1947)、[仍存在的覆盖不足拒绝](../../../backend/mode_pipeline.py#L1484-L1500)。

## 5. A/B/C 与原声证据

### P07 三种制作模式（V2）

| 模式 | 正式声音来源 | 检索/编辑语义 |
|---|---|---|
| A：AI配音 | 正文用TTS；素材中的人声不自动替代旁白 | 旁白匹配用户素材画面；可加入有证据的非语音环境声 |
| B：旁白＋原声 | 旁白TTS，用户标记的quote使用真实素材原声 | 原声找对应take；找不到不能默默用TTS冒充，可由用户明确转旁白 |
| C：只用原声 | 不调用TTS，所有句子对应真实原声 | 开始前重算出处并严格验证稿句是来源ASR中的连续原话；不允许AI写原话 |

**B/C并非完全相同门禁**：当前start对二者检查来源缺失，对C额外检查连续性；B保留不确定/文字差异处理，不能宣称其开始前具有与C同样的严格连续性保证。两者实际渲染原声仍须保持来源、速度、字时和PCM绑定。

依据：[模式规则](../../../backend/mode_rules.json#L36-L92)、[start校验](../../../backend/drafts.py#L1128-L1173)、[模式质量差异](../../../backend/production_modes.py#L1307-L1396)、[真实原声音频验证](../../../backend/mode_pipeline.py#L1604-L1640)。

### P08 原话定位、说话人和跳切（V2／部分条件）

- 使用上传ASR的真实文本、词/段时间和来源提示；文本相似度参考线0.60/0.85，连续性是独立校验，不被高分替代。
- 可显示实际原话、源时间、候选take、低置信提示、SNR和姓名/身份；姓名最长8字、身份12字。
- quote短于1秒列错误，超过20秒提示过长，超过30秒提升为错误级；已知SNR低于18 dB提示杂音。这些是检查规则，不能全称为无法任何方式导出的硬限。
- 本地声纹聚类是可选增强；模型/运行时/许可未满足时如实降级或按required阻断。Provider speaker ID/声纹分组不是实名识别。
- 支持空镜遮跳切、轻微推近、硬切；空镜不足会按规则降级并留记录，不凭空制造遮盖镜头。

依据：[候选排序](../../../backend/production_modes.py#L1102-L1225)、[规则阈值](../../../backend/mode_rules.json#L5-L28)、[可选说话人分析](../../../backend/mode_pipeline.py#L185-L247)、[QuoteEditor](../../../frontend/src/components/QuoteEditor.tsx#L211-L306)。

### P10 语义素材检索（V2）

- 多帧Vision输出描述、动作、关键词、OCR和实体，避免仅文件名匹配。
- 查询/语料分角色向量、dense与词法召回、实体证据补召回、候选集视频向量、LLM精排。
- 默认配置包括2048维向量、粗召回Top15、最终Top10、词法补召回4、最多6个实体二次核验；都是配置参数，不是准确率。
- 有分配/唯一性算法与复用回退，保留低置信与fallback；没有跨所有历史作品的完整可检索媒体资产库。
- **V2与legacy不同**：V2每个确认旁白句构造一个语义视觉节拍。旧管线可自动分多beat；不能把legacy整套能力算到V2。复用链中的多个窗口只是覆盖时长，不等于按多个意思分别配画面。
- V2阶段4没有把原始ASR传入legacy镜头文本融合，因为源时钟不一定一致；ASR仍用于原声和素材池筛选。因此“V2每个视觉向量全面融合ASR/OCR”是不准确的简化。

依据：[匹配入口](../../../backend/matching.py#L506-L654)、[V2单节拍](../../../backend/mode_pipeline.py#L288-L302)、[V2安全素材池和Vision调用](../../../backend/mode_pipeline.py#L1857-L1894)、[模型默认](../../../backend/config.py#L21-L113)。

### P11 AI 配音与本人录音（V2＋服务条件）

- 默认云TTS，有文档上下文、数字读法处理、真实词时间、受限保音高速度处理、逐单元/成片响度与峰值测量。
- 当前慢/正常/快目标为230/265/290字每分钟；这不同于一些历史报告或通用设置默认255。速度调整不是改变真实采访的开关。
- 当前创建时“我自己读”是**先生成AI初版，再在结果逐句替换**；不能宣传为新建时直接上传整篇录音就替代初版。
- 单句可浏览器录音或上传WebM/OGG/WAV/MP3/M4A；需ASR与稿件对齐。词时间缺失时可尝试本地CTC，不会均分文本伪造字时。
- 录音每段20 MiB、最长120秒、每任务最多100段/200 MiB；浏览器实际倒计时还取原句时长推导的更短限额。
- 没有当前用户可管理的自定义TTS音色库或声音克隆产品；“保存本人录音”不等于“克隆本人声音”。

## 8. 质量、导出与“可发布”的区别

### P18 质量报告与人工检查（V2）

### P19 关键变化：当前可确认问题后导出（V2）

当前V2导出有两条路径：

1. **正常路径**：`studio.check_qc()` 与 `require_publication()` 通过。
2. **明确确认未解决问题**：`acknowledge_unresolved=True` 后，V2导出跳过上述两项准入，记录错误数、待确认数和QC阻断摘要。UI显示未通过列表并要求勾选后继续。

第二条**没有把检查变成通过**，也没有取消任务权限、当前版本、done/非busy、磁盘预留、源/输出哈希、规范字幕/图文、生成披露等验证。涉及生成画面的MP3/SRT还会被拒绝，避免丢失必要视觉披露。

因此当前准确承诺是：**“保留问题、显式确认后可以下载”**，不是“任何质量错误均无法导出”，也不是“导出文件已经适合公开发布”。旧单数export/直接下载等兼容路径仍可能保持不同门禁，不能混同。

依据：[V2导出准入](../../../backend/v2_editing.py#L511-L595)、[作业记录与源快照](../../../backend/v2_editing.py#L617-L665)、[下载再校验](../../../backend/v2_editing.py#L726-L747)、[用户确认控件](../../../frontend/src/components/ResultWorkbench.tsx#L1079-L1104)、[旧下载门禁](../../../backend/main.py#L1014-L1026)。

### P20 五种输出（V2）

| 输出 | 当前实际能力 | 不应扩大为 |
|---|---|---|
| MP4 | UI提供720p/1080p；横16:9、竖9:16、方1:1；H.264/AAC、固定30fps；字幕标准/大字/无 | 4K/HDR/任意编码器；智能人物跟踪重构 |
| GIF | 前最多6秒、12fps、宽480的固定画幅策略、无音频 | 全片GIF或任意范围GIF编辑 |
| MP3 | 192kbps，实际人声/旁白单元，不含背景音乐 | 自由选择stems的音频工程 |

- 每任务保留导出作业最多20，全球同时导出容量2；输出后探测时长/尺寸/帧率、哈希及源绑定。

## 10. 模型与本地/云边界汇总

| 能力 | 当前默认/适配 | 实际边界 |
|---|---|---|
| 视觉/OCR、LLM | 默认Kimi K3，保留其他Provider适配 | 配置/权限/网络/额度需外部提供；不读密钥确认本机 |

| 场景检测、转码、合成 | 本地FFmpeg/场景检测/规则 | 消耗本机CPU/存储，非云SaaS托管渲染 |

## 13. 当前没有的完整能力

以下为当前V2范围内的缺口，而不是断言整个仓库毫无相关函数：

- 自由多轨NLE、任意句子重排/拆分/合并、波纹时间线和全参数关键帧。
- 精确锁定候选画面并编辑任意源帧范围；同一旁白按多个语义beat分别选画面的完整界面。
- 只改字幕不改变配音、字幕错字独立校正、字幕多语言翻译/双语排版。
- 声音克隆、可管理多音色、译配对口型、数字人播报。
- 自动长视频高光拆条、按目标时长做多个版本、自动社交发布/排期。
- 主体跟踪式竖屏重构、跟踪马赛克/自动隐私遮挡、AI防抖/超分/插帧、专业HDR色彩流程。
- 全局素材资产库、素材授权台账、品牌模板/MG图表库、任意自有音乐编辑。
- 标准专业工程交换/打包重链接；内部JSON不等于OTIO/FCPXML/AAF。
- 多人同项目协作/评论/审批、账号跨设备同步、可保证的长期归档。
- 实际费用对账/每任务金额上限、真实中文素材集上的可复核质量和速度基准。

## 14. 本次必须修正的旧口径

| 常见旧说法 | 当前代码事实 | 分析影响 |
|---|---|---|
| 所有质量错误都阻止导出 | V2明确acknowledge可导出未解决检查；检查不变绿 | 差异化应是透明审阅，不是绝对安全发布 |
| 每个物理镜头只能用一次 | 当前默认允许真实素材循环，不同逻辑ID | 去重应区分ID与内容；需量化物理重复 |
| 必須再次同意才允许重复 | `_shot_reuse_accepted()` 默认true | UI遗留“同意”文案不能证明用户实际逐次确认 |
| 点哪个候选就用哪个 | 点击描述→重新检索，不锁shot_id | 可控性弱于确定性替换 |
| 工作台能改全部效果 | 当前V2 apply只接速度及句子操作，拒绝旧字幕/增强字段 | 创建、编辑、导出选项应分开 |
| 统一应用必然全部成功 | 换镜可部分成功并发布新版本 | 必须展示逐项结果 |
| 72小时以内绝不删除 | 磁盘不足可提前全站回收合格旧任务/草稿素材 | 保留期与归档可靠性不能混说 |
| AI选效果一定调用模型 | 可本地规则回退；当前提示未区分 | 需要透明标识来源 |
| AI助手保护所有同期行 | 目前只校验固定“同期：”前缀 | 姓名/身份前缀应重点补测 |
| 十阶段与旧实现完全相同 | V2单句单beat、明确模式分流 | 旧算法亮点需重新核对可达性 |

以上是功能/契约边界的静态核查，**未在本次修复产品，也未据此宣布运行缺陷已被复现或修复**。
