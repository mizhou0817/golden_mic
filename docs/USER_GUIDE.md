# 使用指南：制作、修改与导出

[项目首页](../README.md) · [文档目录](README.md) · [快速开始](QUICKSTART.md) · [配置说明](CONFIGURATION.md) · [故障排查](TROUBLESHOOTING.md)

适用于当前 V2 工作区，不是旧课堂或专业时间线教程。开始前须已按[快速开始](QUICKSTART.md)完成配置并确认服务就绪。

## 1. 先认识工作区

- **新作品**：进入“写稿 → 传素材 → 选效果”。A“AI 配音”默认显示，其他方式在“更多制作方式”中。
- **我的作品**：回到已有作品，查看状态、版本和保留期。列表不是账号同步，也不是服务器永久备份。
- **处理页**：查看排队和十阶段处理状态。进度不是准确剩余时间；刷新读取不等于重做。
- **结果工作台**：预览、故事板、逐句修改、应用修改、发布检查、导出。
- **看一条范例作品**：独立只读页面，不创建任务。未安装获批样片时明确不可用，不会拿其他人的任务补位。

“新作品”不会删除旧作品；“草稿随写随存”保存文稿、选项和上传回执等，不保存未上传文件的原始内容。不要在未完成上传/录音时依赖刷新恢复文件。

## 2. 第一条视频：A · AI 配音

### 准备一份短稿和相关素材

下面是**虚构的练习稿格式**，不是实际新闻事实。请根据自己获准素材改写，别把例句当作已经核实的事件：

```text
社区读书活动举行
社区今天举行读书交流活动。志愿者向居民介绍新书。参与者在阅读区分享自己的读书体会。
```

建议先准备 **4–6 段相关的自有短镜头**，例如场地全景、书籍、交流过程和阅读区；不含未获授权人物时更适合初次练习。法律上的使用授权和新闻真实性需要人来确认。稿件较短也可能因素材不匹配而被检查阻止，数量不是成功保证。

**稿件规则：**

- 第一行填写 1–40 字标题，末尾不使用 `。！？.!?；;` 等句末符号，标题不作为正文播报。
- 正文从下一行开始且不能为空，空一行便于阅读；A/B 整份稿件至少 20 字、最多 8000 字，不是正文单独的上下限；超过 3000 字会提示精简。字符数以界面/服务端校验为准，不按字节数。
- 系统分出句子供确认；长句可主动拆开，避免一个画面要撑很久。A 全部为旁白，不写冒充人物原话的同期标记。

### 传素材前，先确认费用与隐私

**一旦选择文件，就可能开始上传、预处理与收费转写，早于“开始制作”。** 素材音频、画面和文字可能提交给配置的服务商。先确认许可、人物声音/肖像授权、第三方处理范围和预算；不要用敏感文件试探上传。

1. 点 **下一步：传素材**，选择真实视频或照片，至少 1 个。
2. 等待每项完成上传和服务器检查。进度到 100% 只表示传输完成，不等于媒体可用、ASR 完成或任务已制作。
3. 检查可用状态、裁剪范围、原声提示和备注。浏览器不能播放的格式不一定服务器不支持，但仍须服务端探测通过。
4. 素材不足提示是估算：普通视频按每 12 秒估计一个可用镜头、图片/已知含语音视频按一个计算；未知语音状态单独提示。它既不是剪辑节奏，也不能保证匹配与最终 QC 通过。
5. 出现中断先用界面提供的重新读取/继续传输入口，不反复新建作品或强行刷新丢掉未上传文件。

### 选效果并开始

第一次选择 **谁来配音 → AI 播音**，保持正常速度。其他画面/字幕/音乐选项按实际内容选择，不必全开。生成补画面不是必需项，也不是解决缺真实新闻素材的捷径。

确认稿件、素材和服务提示后点 **开始制作**。系统显示已接受的任务和十个阶段：检查素材、听声音、分镜、画面理解、稿句处理、找画面、配音、字幕、合成、质量检查。A 可分析素材声音，但不会自动把它替换为同期声。

处理时不要反复提交、重启服务或启用开发热重载。发生网络错误先 **重新读取状态**，确认原任务是否已接收；看见“再试一次”也不等于免费重做。

## 3. B · 旁白 + 原声

适合旁白解释背景、采访原话提供现场证据。选择更多制作方式里的 **旁白 + 原声**，把原声写成：

```text
标题
这是一段旁白。
同期 姓名（身份）：素材中实际说出的连续原话。
这是一段收尾旁白。
```

上面仅示范格式，必须替换为自己的真实稿件、姓名和采访录音，不能照抄示例制造引语。

1. 上传含原话的采访视频和相关空镜。人物身份、人名条文字需自己核实，声纹分组不是实名识别。
2. 在原话匹配区检查 **对上了 / 不太确定 / 没找到** 及实际转写、来源与时间。
3. 听完整上下文，确认说的是这句话且语义未被剪变。文本高分不等于身份、事实、声画同步或音质验证；连续性是另一个门槛。
4. 没找到时补正确素材、恢复真实原话或删掉；B 中确实要改写的内容可明确改成旁白，不能仍标成那个人说的话。

当前文本匹配参考线为 85% 和 60%，但不能靠凑字提高分数绕过出处检查。最终字幕可能按实际说话显示，与稿子不同需人工核对。

## 4. C · 只用原声

C 只剪真实声音，不生成 TTS，不提供旁白或生成示意补画面的替代。

1. 选择 **只用原声**。没稿件时可以先进入第二步上传采访，再回到写稿。
2. 待转写完成，打开 **从转写挑句子**，按成片顺序勾选真实语句；或者粘贴与素材完全对应的原话，一句一行。
3. 补合法的首行标题，核对所有原话和说话人。清空正文并不等于可开始，正式制作前仍需有效原话清单。
4. 在 **原话都拍到了吗？** 解决所有缺失/不确定出处。来源必须连续，不可新增、替换或删掉中间词来拼成新意思。
5. 按需上传空镜遮盖跳切，选择人名条、原声字幕与声音整理；没有可用空镜会如实提示，不能编造素材。

没有真实词时间时只有段级精度，词级裁剪不可用；不按文字长度猜时间。如果服务器要求本地声纹/CTC 能力而尚未供给，应保持阻塞并联系操作者，不勾假许可证或改 required 来继续。

## 5. 在结果工作台统一修改

先播放整条视频，再在故事板中选择需要修改的句子。

| 内容 | 可做的操作 | 注意 |
|---|---|---|
| 旁白 | 改文字、请求换画面、录音/上传人声、删除 | 改文/换镜可能触发收费模型；不是只修改页面文字 |
| 原声 | 连续剪短、换成已有真实 take、删除；B 可显式转旁白 | 不支持改写成“受访者说了别的话”；精度不足就不能词级裁剪 |
| 说话人 | 核对并修改姓名、身份 | 自动分组不证明真实身份或声纹质量 |
| 全片 | 根据可用选项调整节奏、字幕、音乐等 | 历史版本只读；以当前版本的实际检查与报告为准 |

修改先进入**待应用**列表，确认后点 **应用修改 → 生成新版本**。不要关页面就认为已生成；等待后台操作完成和版本更新。接口使用版本条件，遇到“版本已变化”先读最新状态，不重放旧请求。

重命名修改作品的显示名称，不等于重烧视频里的标题。要改变视频内容，必须通过对应内容编辑并重新应用。

### 我自己读 / 我来读

V2 创建时选择 **我自己读** 仍先生成 AI 旁白初版；在结果工作台对旁白句点 **我来读** 或上传该句录音替换。没有替换的句子仍是 AI 声音。

- 首次真实录音由浏览器询问麦克风权限；设备、权限失败按界面提示处理。
- 朗读该句要求的文字，检查对齐/时长结果，通过后加入待应用并统一生成版本。
- 取消录音不应丢掉原编辑；未应用的录音不等于已替换成片。
- C 或原声句不因此成为配音句；旧恢复页面的整篇录音兼容入口不是普通新建流程。
- 服务器可能需要额外对齐能力；失败不能伪造词时、忽略不一致或静默改回 AI 来假装采用录音。

## 6. 发布前检查和导出

**生成 done、预览可播、发布检查通过是三个阶段。**

1. 先应用所有待修改项，并选择当前而非历史版本。
2. 打开 **发布前检查**，修复真正的错误，例如无真实原话、无匹配画面或过长定格。
3. 对允许确认的警告，实际看过/听过/核对过再勾选；数字、人名、日期应查原始来源。普通错误不能用“全部确认”豁免。
4. 已用的生成示意画面必须保留披露；发布门禁不能靠关闭字幕或 `warn` 配置绕过。
5. 点 **导出 / 分享**，等待导出任务成功，下载并完整复看成片。此入口不是公开作品墙、账号分享系统或永久公开链接。

| 格式 | 当前用途 |
|---|---|
| MP4 | 720p/1080p；16:9、9:16、1:1；标准/大字/无字幕选择，裁切后仍要复看 |
| GIF | 前 6 秒，无声音，不是全片 GIF |
| MP3 | 旁白/原声人声，无背景音乐 |
| SRT | 字幕文件，仍需核对文字和时序 |
| PNG | 当前预览帧封面，先选好画面 |

导出仍受媒体时长、分辨率、总大小与版本校验约束，不保证任何码率/长片都能导出。导出过程中如果作品又发生修改，旧文件仍对应其捕获版本，需要另行导出新版本。

## 7. 历史、复制、恢复与删除

| 操作 | 实际含义 |
|---|---|
| 查看历史作品/版本 | 读取已有内容，不自动制作或续费；历史版本不可直接修改/导出为当前版本 |
| 恢复这个版本 | 显式操作，生成/切换受版本规则保护的当前结果，不覆盖抹除历史证据 |
| 复制一份 | 已完成版本的独立作品，复制所需媒体与已保存内容；不包含未应用编辑，不重新跑 AI，保留期仍有上限 |
| 以其他模式继续 / 返回编辑 | 按界面恢复可用稿件/上传回执，先核对来源与状态；缺媒体或过期时不能假装恢复可用素材，开始制作仍需明确操作 |
| 再试一次 | 只在服务端允许时重试相同输入；先确认上一请求状态，不是免费、无条件或自动续跑 |
| 删除 / 取消并删除 | 确认后请求删除服务端作品、版本及媒体；以服务器成功为准，不退款。仅移除浏览器历史记录不等于服务器删除 |

不要把单独的作品 URL 当成访问备份：V2 还需要浏览器保存的任务凭据，匿名会话不会给别人授予该作品权限。切换浏览器、清站点数据或从 8000 换到 5173 后，历史可能不同，不能靠公开服务器全局列表找回。

V2 草稿 24 小时空闲到期，终态作品（含失败）72 小时，上传自创建起最长 72 小时。自动保存不等于永久保留，及时另存获准导出的成片；恢复/复制不是无限续期办法。维护/备份见[运行维护](RUNBOOK.md)。

## 8. 素材边界速查

下面是当前上限，实际服务器可进一步收紧，优先看页面提示：

| 项目 | 限制 |
|---|---|
| 视频 | MP4、MOV、AVI、MKV；仍须可解码且服务端探测通过 |
| 图片 | JPG/JPEG、PNG、GIF；GIF 按首帧处理，不保留动画 |
| 数量 / 大小 | 最多 20 个；一般单文件 500 MiB；图片另限 50 MiB / 20 MP；总量 5 GiB |
| 源时长 | 单个 30 分钟，总计 60 分钟，按原始时长检查，不能靠裁剪绕过 |
| 源几何 | 最大 7680×4320、120fps；不是最终 8K/HDR 输出承诺 |
| 上传分块 | 8 MiB，由程序管理，不必手工拆文件 |

当前不提供实时协作、账号云同步、全功能专业 NLE、自动配音身份认证或无限保留。更多症状处理见[故障排查](TROUBLESHOOTING.md)；当前验证与未完成项见[日期交付记录](V2_PRODUCT_DELIVERY_20261003.md)，不以合成测试替代你的实际成片核验。
