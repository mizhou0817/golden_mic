# 故障排查

[项目首页](../README.md) · [文档目录](README.md) · [快速开始](QUICKSTART.md) · [配置说明](CONFIGURATION.md) · [运行维护](RUNBOOK.md) · [使用指南](USER_GUIDE.md)

**先停止重复提交，再定位错误。** 页面刷新、重启服务、重新生成不是同一种操作。不要为了验证修复反复调用付费模型；不要清空浏览器存储、删除任务目录或关闭安全校验。

## 1. 页面能开，但显示未就绪

先区分三种情况：

| 看到的现象 | 含义 | 下一步 |
|---|---|---|
| `/health/live` 返回 200 | 进程能响应，不代表能制作视频 | 查看 `/health/ready` 的状态和失败检查名 |
| `/api/config/availability` 返回 HTTP 200，但正文 `status=not_ready` | 此浏览器接口用正文表达就绪状态 | 不要只看 HTTP 状态码；按下表定位 |
| `/health/ready` 返回 503 | 启动检查不通过，或正在排空/磁盘不足 | 处理失败项；需要重新加载配置的按维护流程重启 |

开发模式直接启动 Uvicorn 可以在未就绪时展示界面，**不是成功制作验收**。VS Code 的 `Golden Mic: Start local server` 任务更严格：先执行预检，未就绪就拒绝启动。生产应用本身也拒绝未通过预检的启动。不要更换启动方式来掩盖生产问题。

| 失败检查或提示 | 安全处理 |
|---|---|
| `settings`、配置字段缺失 | 对照[配置说明](CONFIGURATION.md)检查工作目录、进程环境和对应模板；不要输出全部环境变量 |
| `provider_configuration` | 补齐实际使用的 Kimi、共享 Embedding、ASR/TTS 配置；LLM 错误可能来自 Kimi 分屏，不能只看 `LLM_PROVIDER` |
| `frontend_dist` | 按[快速开始](QUICKSTART.md)使用正常构建流程，确认静态资产与清单配套；不要手改摘要让不匹配通过 |
| `font_asset` | 恢复发布包内经过审核的字体及许可证；不要用任意系统字体或忽略摘要替代 |
| `media_capabilities` | 检查启动服务的那个终端是否能找到同一套 FFmpeg/ffprobe，见下一节 |
| `data_directories`、`disk_capacity`、`insufficient_disk_space` | 检查操作者指定目录的权限、磁盘挂载和空间；先备份并按保留策略处理，不要调低安全余量硬闯 |
| `local_speech_*`、`bundle_manifest_missing` | 查看[本地语音配置](CONFIGURATION.md)；缺权重、依赖、审核或清单就保持不可用，不自动下载/开启开关 |
| `service_draining` | 维护期间正常；联系操作者确认排空原因，不能自行取消别人的维护 |

预检会创建/检查数据和缓存目录、写入并移除检查文件，运行媒体工具；它不是只读诊断。就绪接口复用启动快照，改环境变量或补模型后刷新页面不会重新预检。详细流程见[运行维护](RUNBOOK.md)。

## 2. Windows 启动或构建失败

### PowerShell 提示禁止运行脚本

不要降低系统执行策略。使用项目虚拟环境里的 Python 可执行文件直接运行，或使用 `npm.cmd` 而不是被策略拦截的 PowerShell 包装脚本。安装和启动步骤见[快速开始](QUICKSTART.md)。本项目不要求通过放宽执行策略才能运行。

### 找不到 FFmpeg，或升级后旧路径失效

WinGet 的安装目录带版本，不能照抄旧报告中的 bin 路径。已有[VS Code 启动任务](../.vscode/tasks.json)会先查当前 PATH，再在当前用户 WinGet 的 Gyan.FFmpeg 包目录动态寻找编码器。手动启动时也应使用实际安装位置，并确保 FFmpeg/ffprobe 在**该服务进程**的 PATH 中。

仅在另一个终端能执行不够。FFmpeg 还需支持 libx264、AAC 和 ass、loudnorm、ebur128、silencedetect、perspective 等能力。不要下载来源不明的替代程序或略过能力检查。

### OneDrive 提示云文件提供程序错误，或读取依赖失败

先由文件所有者将项目与依赖设为“始终保留在此设备上”，确认文件可本地读取；必要时按[开发指南](DEVELOPMENT.md)在新的非同步本地工作区恢复项目。不要搬移运行中的数据目录，不要删除旧失败记录。云文件读取错误不是放宽字体/模型/构建摘要检查的理由，也不能以替代构建成功证明同步问题已修复。

### 端口 8000 被占用

先确认是否已有自己的服务，以及它由哪个终端或服务管理器启动。**不要按端口批量杀进程，也不要复制历史 PID 停服务。** 需要替换自己的服务时，按[运行维护](RUNBOOK.md)排空并确认空闲后停止；归属不明则请操作者处理。

## 3. Vite 页面正常，API 或历史列表不正常

- 普通使用优先用后端同源页面，通常是本机 8000 端口，避免混用不同 Origin 的浏览器缓存。
- [Vite 开发配置](../frontend/vite.config.ts)把 `/api` 和 `/health` 代理到本机 8000；浏览器同源只说明请求入口一致，**不保证后端授予 `local_history`**。后端还核验直接回环客户端、回环 Host、非生产模式、无转发头；代理附加 `Forwarded` 或 `X-Forwarded-*` 等头会使本地特权不可用。
- 不要删安全头、伪造身份或关闭 Origin 校验来恢复列表。回到原来的页面 Origin/浏览器会话，保留任务访问凭证；生产无全局任务索引是正常边界。
- `vite preview` 默认 4173 预览构建页面；当前 Vite 8 默认继承 `server.proxy`，`/api`、`/health` 仍代理到 8000，**但不会启动后端**。4173 不在开发模板默认 Origin 中，也有独立站点存储，不作为正常制作入口；不要关闭 Origin 检查来绕过写入失败。开发入口见[开发指南](DEVELOPMENT.md)。

## 4. 上传、排队或生成失败

| 提示/状态 | 先做什么 | 不要做什么 |
|---|---|---|
| 文件过大、时长/格式不支持、413/422 | 对照界面实际限制；本地准备合规素材；不确定的时长不能当作 0 | 不要改扩展名假装格式正确，不要放宽服务端限制 |
| 等待中、队列已满 | V2 等待上限 50，与旧 pending 5、并发 1 分开看 | 不要开多个 worker，也不要重复点开始 |
| 429 或预算受限 | 区分应用小时预算与提供方限流，等待预算窗口并联系操作者 | 不要轮换会话/IP、删除账本或提高限额规避预算 |
| ASR/Vision/TTS 超时、权限/额度错误 | 记录阶段和脱敏错误类别，由操作者核对服务授权、配额与网络 | 不要把“预检通过”当作凭证已验证，不自动付费重试 |
| 原声未匹配、`quote_missing` / `quote_unverified` | 核对稿件原话与素材的实际连续语音，按[使用指南](USER_GUIDE.md)修改或补素材 | 不要伪造逐字时间戳、说话人，或强行跳过 C 模式原声门禁 |
| 素材不足 | 增加获准使用且相关的真实素材，或缩短稿件 | 不要把估算镜头数当作成片保证，不要随手开启付费补画面 |

提交失败后先读回同一任务状态，确认是否已接收。`retrySame` 只有在服务端确认同输入、实现/模型绑定及已有提供方回执可复用时才允许；不是通用免费重试。未知或进行中的付费结果不能自动重放。重启不会自动续跑中断的生成。

## 5. 作品打不开、无法导出或录音失败

- **404**：可能是链接、权限或凭证问题，不等于确定过期。回到原会话/原 Origin；不要把完整媒体 URL 发给别人检查。
- **410 且 `task_gone`**：服务端确认作品已不可用；V2 终态保留 72 小时，旧本地 `TASK_TTL_HOURS=0` 不会延长它。浏览器列表记录不等于服务端文件仍存在。
- **409 或版本已变化**：先读取最新版本，核对待保存修改；不要强行覆盖或重放旧写请求。
- **生成完成但导出禁用**：逐项处理当前版本的质量错误和待确认项。`QUALITY_GATE_MODE=warn` 不关闭发布/导出的硬检查；历史列表不是永久发布许可。
- **下载/拖动播放失败**：由操作者检查同源授权、有效版本和代理的 Range 支持；正常分段响应可以是 206。不要把任务令牌追加到公开命令，不要重复拼接鉴权参数，也不要粘贴带 token 的 URL、Cookie 或请求头。
- **录音权限被拒绝**：检查本站麦克风权限、设备是否被占用及浏览器是否处于可信上下文（通常为 HTTPS 或 localhost）。取消后保留原编辑；不要用自动授权脚本假装物理麦克风验收。
- **公开范例不可用/503**：可能尚未安装获批样片。当前[交付记录](V2_PRODUCT_DELIVERY_20261003.md)明确公开范例仍待供给；不要随意公开用户任务代替范例。

## 6. 仍无法解决时，提供最少信息

向维护者提供：发生时间、操作步骤、浏览器/系统版本、页面状态、失败检查名、HTTP 状态码与脱敏错误类别、是否存在待处理任务。共享前删除私人稿件、素材信息和用户路径。

运行日志的位置取决于实际启动方式，应由操作者从启动回执或服务管理器确认，本文不假定某个历史日志文件仍存在。**不要上传原始日志、堆栈、浏览器网络导出、截图中的密钥或完整环境变量**；日志自动脱敏也不是可直接公开的保证。

保留原失败和现有证据；按[运行维护](RUNBOOK.md)安全止损。历史合成测试通过不能证明本机、真实提供方、物理麦克风或生产环境已经修好。
